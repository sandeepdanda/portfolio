## What

A full-stack health-club platform for member management, bookings, subscription payments, auto-renewal, and administrative analytics. MEMBER and ADMIN roles keep customer and operational workflows separate.

## Approach

A Spring Boot REST API handles authentication, memberships, bookings, and payments behind a React client. JWT secures the role-based flows. The app uses H2 for local development and tests, with PostgreSQL configuration for production.

## Stack

Java 21, Spring Boot, Spring Data JPA, React, PostgreSQL, H2, and JWT.
